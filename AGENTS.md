## Критическое уточнение владельца — НЕ ДЕЛАЙ РОЛИКИ ЗА ЗАВОД
Пользователь прямо запретил подменять автономный выпуск тем, что ассистент вручную вызывает Create Audio Voice, создаёт один сценарий и кладёт одиночный Deep в inbox. **Работать надо над автоматическим исполнителем, а не над отдельными Shorts в чате.** Для НОВЫХ эпизодов по умолчанию `gustava_selfhosted_qwen3` и проверенный HTTPS failover cloud → Windows → третья машина. Deep — только ранее полученные подлинные и уже SHA-закреплённые записи. Автоматический производственный резерв НЕ считает Deep-сценарий без записи полноценным заданием. Готовность API по одним настройкам не подтверждает реальный WAV. Планировщик не запускает пустой рендер и не отправляет фиктивный Buffer; при отсутствии голосовых узлов фиксирует честный BLOCKED. Не разрешать автопубликацию без реальных QA, проверки изображения, Buffer Post ID и публичного YouTube URL. Цель — полностью повторяющийся цикл без ручного участия пользователя, а не отчёт об одном созданном файле.

## Ротация оригинальных DEEP-записей
**Только архив ранее разрешённых Deep и ремонт аудио. Для новых автономных Shorts Deep Inbox НЕ является способом снабжения.** `cloud-shorts/deep-voice-inbox.json` — исходный неизменяемый пакет. Для каждого следующего дня создавай/дополняй `cloud-shorts/deep-voice-inbox-YYYYMMDD.json` (максимум 20 записей на файл), с `version=1`, `voice_id=deep` и массивом `records`. Не затирай существующие записи, не повторяй `episode_id` в разных пакетах; для отклонённой ASR озвучки исправляй её исходную запись через PR. Каждый новый пакет автоматически проверяет `deep-inbox-ingest.yml`; записи и отказы сохраняются в Git. 20 — лимит пакета, не всего завода. Генерация в ChatGPT допускается только оригинальным `voice_id=deep`, если инструмент реально доступен.

## Как работать с кодом
Перед изменением смотри реальный GitHub Actions лог и воспроизведи ошибку тестом. Применяй минимальный PR; запускай весь `unittest discover -s cloud-shorts -p 'test_*.py'` и не отключай проверки ради зелёного статуса. Смена конвейера, голоса, раскладки, издателя, чисел или разрешений требует явного согласования. **Код может быть правильным, но фабрика не считается восстановленной, пока Buffer scheduled >0 и свежий реальный YouTube-ролик не подтверждены.** Если внешняя поставка DEEP не работает — сообщай блокер, никогда не заменяй голос.
