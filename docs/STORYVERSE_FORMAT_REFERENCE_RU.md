# GUSTAVA — оригинальные сюжетные Shorts (формат STORYVERSE)

## Проверенный референс

Пользователь выбрал: https://www.youtube.com/shorts/r39bw-GBNKU
Открыт и проанализирован отдельно, **без добавления чужого видео, музыки, персонажей, точных реплик или файлов в репозиторий и выпуск**.

Фактическое видео: **«Мороз держал их 108 дней. А потом пришла весна 😨 Финал»**, канал Survive Alert, длительность ~113,95 с (1:54), русский язык, вертикальное 9:16. История в описании обозначена как **вымышленная**.

### Что составляет формат (не копируем конкретный сюжет)

- Вымышленная, напряжённая мини-история: герой, цель, измеримые ограничения, действия, кризис, развязка и финальная новая загадка.
- Визуальная система: на объёмном, атмосферно освещённом окружении — простые плоские/контурные мультгерои с выразительными лицами и тонкими конечностями. Для GUSTAVA создаём **свои** силуэты, одежду, локации и художественные решения.
- Сильные конкретные детали на экране: счётчик дней, показания прибора, часы — **только если они связаны с сюжетом**, а не декоративная случайность.
- Русский закадровый рассказ; крупные читаемые **синхронизированные по словам** субтитры: преимущественно белый шрифт с тёмным обводом. Не допускать наложения, выпадения букв, вылезания в кнопки Shorts.
- Монтаж последовательный и причинно-следственный: персонаж должен успеть выполнить действие, о котором говорит рассказчик. Никакого A/B/A/B через секунду.
- Диапазон длительности: около 100–125 секунд для полноценной истории; в пилоте 114 с / 19 частей, каждая 6 с. Это **не** искусственный клип на 9–20 секунд.
- Завершить конкретную проблему героя, после этого можно оставить интригующий намёк на продолжение. Не заменять развязку бессодержательным «часть два?».
- Юмор, тревога и драма допускаются, но история должна быть цельной, а не набором фактов, фотографий или спором «А или Б?».
- Текст/голос/фрагменты видео референса не использовать в готовой продукции. Сюжеты полностью новые, вымышленные; не выдавать за реальные происшествия.

## Зафиксированный оригинальный пакет

**Серия:** «Хроники после полуночи» — 10 разных концепций; не ограничена тематикой мотоциклов.
**Пилот:** «Лифт на минус четвёртый» — 19 связанных эпизодических сцен, полный русский закадровый текст и действия/ракурсы/SFX. Фиксированные герои: Лера (лиловая куртка, красный шарф), её брат (синяя куртка, чёрная шапка) и восемь детей.
**Файлы:**
- `series/original-chronicles/season1.json` — сцены, визуальная библия и идеи.
- `cloud-shorts/storyverse.py` — CLI для валидации, извлечения сценария и генерации идей.
- `cloud-shorts/test_storyverse.py` — тесты fail-closed, хронологии, голоса, оригинальности и состояний.

## Компоновка для производства

Возможный отдельный рендерер: построить оригинальные фоны 3D, затем **детерминированно накладывать одинаковые 2D-персонажи** по худож. библии с управляемыми позами, а не генерировать каждый кадр с новым лицом. Для каждого сценического кадра нужна проверка: тот ли персонаж, костюм, предмет, действие; есть ли движение (нет заморозки), нет ли артефактов текста в кадре.

Формат: 1080×1920, 30 FPS, H.264/AAC, 9:16; раздельные дорожки диктора, музыки и SFX; отсутствие чередования голосовых каналов; звук описываемого действия должен совпадать со сценой. Диктор — **только авторизованный GUSTAVA DEEP**, оригинал закрепляется по SHA; никакой Silero, V6, искусственного понижения или подмены. При отсутствии проверенного Deep-войса выпуск блокируется, а не заменяется.

### Контрольные этапы (строго различать)

1. `creative_brief_not_rendered`: только текст, **ни MP4, ни пост в Buffer, ни публикация**.
2. `rendered_preview`: реальные исходные клипы + собранный MP4, проверяемые исходные SHA, кадры, ASR.
3. `qa_approved`: подтверждено визуальное единообразие героев и сцен, точный русский звук Deep, субтитры/тайминг, оригинальность и право использования, отсутствие замороженных кадров и повторов.
4. `buffer_scheduled`: есть фактический Buffer ID.
5. `youtube_published`: есть независимая проверка публичного YouTube URL/ID.

**Никаких ложных обещаний:** наличие первого сценария или GitHub Actions без MP4 не означает, что завод генерирует или публикует такие видео. Уже работающий двухсценовый генератор не подходит для этой серии и не должен подхватывать пакет как готовый Shorts. Публикация остаётся заблокированной до реального визуального, голосового и редакционного QA. Основной контракт `cloud-shorts/factory_contract.json` и действующие квоты категорий в этой ветке **не меняются**.

### Как проверить сценарии

```sh
python cloud-shorts/storyverse.py --validate
python cloud-shorts/storyverse.py --list
python cloud-shorts/storyverse.py --pilot-brief
python -m unittest discover -s cloud-shorts -p 'test_storyverse.py' -v
```

Для следующих сюжетов `storyverse.generate_draft` может опросить установленную локальную Ollama, но полученный сценарий проходит те же строгие проверки структуры, времени, языка, визуальных действий и общей длины; если модель не смогла дать все 19 сцен — **ошибка, а не фиктивный ролик**.
