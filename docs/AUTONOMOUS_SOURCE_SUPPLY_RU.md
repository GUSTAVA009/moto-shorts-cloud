# Постоянный реестр новых лицензированных кадров

GitHub Actions запускает пополнение сценариев и исходников без открытия
ChatGPT. Перед каждой новой попыткой надо перечитывать исходный контракт
docs/FACTORY_CONTRACT_RU.md и AGENTS.md.

Ранее одно удачное видео из Wikimedia Commons CC0 терялось, если с первого
поиска не получалось собрать двухкадровый сюжет. Новый модуль
cloud-shorts/cc0_source_pool.py сохраняет только подтверждённые метаданные
CC0 в ветке render-ledger по пути automation/cc0-source-pool.json.

Разрешено сохранять: официальный URL файла, страницу автора, имя автора,
точный Commons SHA-1, размер, указание лицензии CC0 1.0.
Запрещено сохранять: чужие платные файлы, видео YouTube, персональные
локальные файлы, обходить лимиты сайта, подделывать лицензии и заявлять
«готовый MP4», пока есть только URL и метаданные.

При HTTP 429 новый поиск переносится на следующий штатный запуск.
Прошлые CC0-кандидаты сохраняются; отбор материала продолжает проверять
реальные неизрасходованные source IDs, различных правообладателей и
различные действия. Каждое использование Commons-файла перед рендером
повторно проверяет живую лицензию и содержимое (SHA-1/размер).

Реестр кандидатов никак не заменяет DEEP, финальную проверку движущихся
кадров, русский ASR, проверку MP4, редакционное одобрение или Buffer.
Отсутствие официального API GUSTAVA DEEP всё ещё блокирует работу
полностью автономной студии. Не пытаться обходить запреты провайдера
на неавторизованных ботов и скрытые API.
