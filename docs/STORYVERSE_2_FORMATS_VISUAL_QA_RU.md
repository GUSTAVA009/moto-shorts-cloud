# GUSTAVA — два утверждённых формата коротких историй

Статус: **художественное направление принято; публикация только после визуального QA**.
Ни один предыдущий MP4 не объявляется безартефактным только на основании успешного FFmpeg-декодирования.

## Формат A — PAINTERLY CINEMA

* **Внешний вид:** рисованные объёмные зимние пейзажи; глубокие синевато-фиолетовые оттенки, мягкий свет фар, снег нескольких планов, живописные фактуры без глянцевого CGI.
* **Персонаж:** единый закреплённый 2D-риг и согласованный дизайн на протяжении истории. Руки, глаза, одежда, пропорции не должны изменяться самопроизвольно.
* **Анимация:** живое многоплановое изображение + управляемые движения персонажа, транспорта и дверей. Один только zoom/pan изображения НЕ считается полноценной анимацией сюжета.
* **Техника:** 2D-слои с масками глубины, отдельными объектами и временной шкалой (Canvas/HTML или композиция); динамика по явным keyframe. Визуальные эффекты — снежинки, отражения, свет, туман.
* **Опорная версия:** `AVTOBUS_WINTER_V2_DEEP_SYNCED.mp4` (атмосфера, цвет, формат; не абсолютный эталон анатомии).

## Формат B — HYBRID CEL × 3D

* **Внешний вид:** простые 2D-персонажи с белым лицом и двумя глазами + единый постоянный 3D-мир (здания, дороги, автобус, интерьер).
* **Геометрия:** транспорт и здания создаются один раз и переиспользуются между ракурсами. Колёса, крыша, пороги, двери и контакт персонажа с дорогой/ступенями должны быть физически согласованы.
* **Двери:** нельзя анимировать створки через пространство, по которому идёт герой. У автобуса — согласованные раздвижные створки; свободный проём измеряется **в мировых координатах**, не только визуально. Путь героя проходит между створками.
* **Камера:** безопасный frustum, отсутствие пересечений с фасадами, стенками автобуса и служебными объектами; проверка кадра до и после всех движений камеры.
* **Риг:** отдельные связанные сегменты рук и ног, две глаза, одна пара ступней; ключи ходьбы с опорой на поверхность.
* **Техника:** Blender с фиксированными моделями и физическими keyframes, затем FFmpeg для компоновки голоса, SFX и титров.
* **Опорная версия:** `BUS00_FORMAT_B_SAFE_SLIDING_DOORS.blend` / `AVTOBUS_HYBRID_V3_SAFE_DOOR_12S.mp4` (технический прототип, не релиз).

## Общее для двух форматов

* Оригинальные сюжеты; референсы используются как художественное направление, не для покадрового копирования.
* В кадре **нет**: GUSTAVA STORYVERSE, номера серии, этапа сцены, счётчика кадров, технологических плашек и посторонних предметов. Субтитры допустимы только по смыслу.
* Озвучка: **реальный выбранный GUSTAVA DEEP**; недоступность — остановка, не молчаливая подмена.
* SFX: лицензированные записи / разрешённый синтез; синхронизация через **номер кадров действия**, а не приблизительные «время по тексту».
* Приоритет события: (1) реальная 3D/2D-анимация, (2) начальный и конечный кадр действия, (3) звук события, (4) речи/субтитры. Например, звук начала открытия дверей = кадр начала движения дверей.
* Звук голоса — центр стереопанорамы; без дубля через разные каналы и без искусственного занижения тембра.
* Для вертикального YouTube: 1080×1920 и безопасные зоны под UI платформы. Широкий 1920×1080 — только для отдельно запрошенного формата.

## Обязательный выпускной контроль (автоматический + визуальный)

1. **Геометрия/риг:** уникальность модели, фиксированное число колёс/глаз/конечностей, двери и ступени, реальный проход и контактные тени; проверки интервалов по каждому keyframe.
2. **Камера:** инспекция начала/середины/конца каждого плана, особенно на резких поворотах и приближениях. Объекты на переднем плане не могут произвольно перекрывать героя и смысловое действие.
3. **Непрерывность:** не возникает лишних линий, объектов, рук, лиц; нет телепортаций, незапланированных исчезновений или перемещений между дублями.
4. **Реальные действия:** если звучит «открылись двери», двери действительно открываются; если «герой вошёл», видны переход ног и прохождение порога без стены или створки поперёк.
5. **Звук:** реестр событий `frame/start/end/asset/license/volume`; проверка совмещения начала звука с движением. Не добавлять шаги, когда персонаж неподвижен.
6. **Титры:** читаемость, отсутствие наложений и лишних надписей; соответствие времени произнесения.
7. **Видео:** полное декодирование, целостность MP4, постоянный FPS, правильная длительность, сохранность звука, метаданные SHA256.
8. **Решение:** `READY_FOR_REVIEW` только после визуального просмотра; `PUBLISHABLE` только после прохождения всех проверок. Брак остаётся закрыт для автопубликации.

## Критический кейс №1: красная перекладина в автобусе

В версии `1000159124.mp4` распашная створка и внутренний структурный элемент заслоняли вход. Исправление: заменить на фиксированные раздвижные панели, удалить стойку/пояс в зоне проёма, контролировать путь героя в мировых координатах и переснять камеру. Не считать проём исправленным по одному красивому стоп-кадру: проверять **начало, середину, конец и весь путь**.

## Статусы

* **Формат A:** признан подходящим по художественному направлению; требуется развитие отдельной анимации персонажей и дверей.
* **Формат B:** признан подходящим как производственный подход; прототип v3 исправляет конкретное перекрытие дверью, но всё равно требует финального просмотра.
* Автоматическая публикация обоих форматов блокируется до получения визуального одобрения.
