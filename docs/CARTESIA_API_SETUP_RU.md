# Официальный Cartesia Sonic 3.6 API — подключение к заводу GUSTAVA

**Статус:** код интеграции и тесты не означают, что в GitHub подключён
ключ или оплачена коммерческая лицензия. Исторические DEEP-ролики сохраняются.
Это решение разрешено владельцем 01.11.2026; новая модель может использоваться
только с настоящим мужским русским голосом.

## Защита API-ключа

Не вставляйте ключ в файл Git, .env в публичном репозитории, Issues,
логи GitHub Actions, скрипты, сообщения PR или GitHub Variables.
Создайте Actions Secret **CARTESIA_API_KEY**:
https://github.com/GUSTAVA009/moto-shorts-cloud/settings/secrets/actions/new
Подключённый GitHub MCP не имеет метода для записи Actions Secrets;
поэтому установка секрета через него **не подтверждена**.
Если токен ранее был отправлен в переписку, лучше выпустить новый секретный
ключ на https://play.cartesia.ai/keys и отозвать старый.

## Сначала проверить голос, без расхода TTS-кредитов

Cartesia GET /voices?language=ru&gender=masculine
с заголовками Authorization: Bearer <секрет>, Cartesia-Version: 2026-08-14.
Выберите голос с language=ru либо native accent ru-RU и gender=masculine,
status=active. Его реальный UUID запишите в публичную репозиторную
переменную CARTESIA_VOICE_ID; это НЕ API-ключ. Не сочиняйте UUID.

## Репозиторные переменные GitHub Actions

- GUSTAVA_TTS_PROVIDER = cartesia_sonic36
- CARTESIA_VOICE_ID = <реальный выбранный UUID из официального API>
- CARTESIA_TTS_ENABLED = 1 (только после безопасной установки секрета)
- CARTESIA_MONTHLY_CHAR_LIMIT = 15000 (необязательная жёсткая квота)
- CARTESIA_COMMERCIAL_PLAN_CONFIRMED = 1 **только** после подтверждения
  тарифа с коммерческими правами; на Free оставить unset/0.

Настройки переменных:
https://github.com/GUSTAVA009/moto-shorts-cloud/settings/variables/actions

Обязательно **выключите сверхлимитные расходы (overages)** в панели
https://play.cartesia.ai/ и следите за фактическим лимитом.
Квота 15000 — внутренний защитный предел поверх квот провайдера,
а НЕ гарантия бесплатных или неограниченных запросов.

## Что происходит на очередном запуске GitHub Actions

1. Поставщик создаёт **новый** оригинальный сценарий с закреплённым UUID.
2. Оператор очереди видит Cartesia-кандидата, только если есть выбранный
   голос, включена TTS и установлен Secret; без них резерв не расходуется.
3. Для нового приватного MP4 резервируется максимум 350 символов из
   месячного реестра `render-ledger/voice-usage/cartesia-YYYY-MM.json`.
4. GET /voices/{id} проверяет status, masculine и native Russian.
   Затем ровно один платный POST /tts/bytes с model_id
   sonic-3.6-2026-08-27, language=ru и WAV 44.1kHz PCM mono.
5. WAV конвертируется в mono 24kHz; фиксируются UUID, модель,
   SHA-256 исходного ответа, SHA-256 WAV и полный хеш текста.
   Повторные визуальные рендеры в той же job используют ТОЧНО эту запись.
6. Независимый source ASR и ASR финального MP4, движение кадров,
   лицензии, проверка титров и редакторское одобрение обязательны.
7. **Новый Cartesia-выпуск не допускается в публичный Buffer** до
   явного CARTESIA_COMMERCIAL_PLAN_CONFIRMED=1.

## Важное ограничение

При неизвестном результате API-запроса его стоимость уже учтена и
повторная генерация тем же episode_id заблокирована. Приложение не
восстанавливает платные вызовы по принципу «попробуем ещё раз».
Секрет не получен через имеющийся GitHub-коннектор; реальное подключение
и запуск на live credits нельзя объявлять завершёнными без проверки.
