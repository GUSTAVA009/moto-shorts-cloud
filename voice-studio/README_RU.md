# GUSTAVA Voice Studio — собственный голос, сайт и API

**Состояние:** рабочий исходный код веб-интерфейса и серверного API. Локальный GPU-сервер и домен ещё не развернуты. Никакой реальной синтезированной записи Qwen пока не подтверждено.

## Законный оригинальный диктор

Запись Sergei из Cartesia **не используется для клонирования или обучения**.
Условия Cartesia ограничивают разработку конкурирующих моделей/сервисов с использованием её аудиовыходов:
https://www.cartesia.ai/legal/terms

Используем только Qwen3-TTS 1.7B VoiceDesign (Apache 2.0), который создаёт оригинальный голос по самостоятельному текстовому описанию. Один сгенерированный эталон затем закрепляем через SHA-256. Каждое следующее аудио создаётся Qwen3-TTS 0.6B Base с этим эталоном — без независимого случайного тембра при каждом запросе.
https://github.com/QwenLM/Qwen3-TTS
https://github.com/linkary/qwen-tts-server

## Архитектура

Браузер / YouTube-завод → HTTPS voice.hapychrust.ru → GUSTAVA Web/API → приватный Qwen Server с GPU.
Ключи gvk_* выдаёт собственный сервис. SQLite хранит только их хеши; ключ можно отозвать. Нет минут/кредитов Cartesia. max_chars_month=0 означает отсутствие месячной квоты; отдельное ограничение запросов в минуту защищает GPU от флуда.

## Запуск на авторизованной NVIDIA-машине

Нужны драйвер NVIDIA, Docker Compose, NVIDIA Container Toolkit. На первом запуске скачиваются открытые модели (значительный объём). Для 1.7B и 0.6B на RTX 3060/4060 12GB производительность необходимо проверить; могут потребоваться загрузка моделей по очереди или более мощная GPU.

1. Перейти в папку voice-studio.
2. Скопировать .env.example в локальный .env (этот файл не публиковать).
3. Дважды выполнить: python3 -c "import secrets;print(secrets.token_urlsafe(40))"
4. Вставить ДВА разных случайных секрета в VOICE_STUDIO_ADMIN_TOKEN и UPSTREAM_API_KEY.
5. Запустить: docker compose up -d --build
6. Проверить: curl http://127.0.0.1:8080/health
7. Открыть на этой машине: http://127.0.0.1:8080/

Важно: веб-API слушает только 127.0.0.1:8080; внутренний Qwen :8000 не публикуется. Для наружного HTTPS нужен Caddy + публичный IP либо Cloudflare Tunnel на компьютере за NAT. voice.hapychrust.ru — **предложенный поддомен, DNS пока НЕ настроен**.

## Первый запуск сайта

Ввести собственный VOICE_STUDIO_ADMIN_TOKEN; подтвердить создание оригинального голоса и нажать «Создать и закрепить голос». После генерации прослушать эталон и пройти независимые проверки русского произношения. Выдать ключ YouTube Shorts Factory и скопировать его из панели единственный раз.

## Пример HTTP API

POST https://voice.hapychrust.ru/v1/audio/speech
Authorization: Bearer <YOUR_GVK_KEY>
X-Idempotency-Key: moto-episode-001
Content-Type: application/json

JSON: {"text":"Дорога только начинается!","voice":"gustava-original-v1","response_format":"wav"}

Ответ: WAV + X-Audio-SHA256 + X-Voice-ID + X-Reference-SHA256. Один и тот же Idempotency-Key с тем же текстом возвращает сохранённую запись; при неизвестном состоянии генерация не повторяется вслепую.

## Безопасность

- Только оригинальный голос, не образец Cartesia; эталон и хеш на приватном диске.
- Административные маршруты требуют X-Admin-Token; ключи выдаются 256-битные и не хранятся в базе открыто.
- Собственная БД SQLite резервирует GPU-запрос до начала генерации; повторные попытки не удваивают работу.
- Внешний HTTPS обязателен для сетевой эксплуатации, ключи не должны попасть в GitHub или публичные логи.
- Результат WAV сам по себе не доказывает завершённый Shorts: завод по-прежнему обязан проверить независимый ASR, визуальное качество, лицензии, редакционное одобрение и Buffer ID.
