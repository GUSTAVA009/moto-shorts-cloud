# GUSTAVA Enduro — автоматическая фабрика мото-Shorts

**Действующая конфигурация на 29 октября 2026 года.** Канал:
[YouTube @gustava009](https://www.youtube.com/@gustava009).
Новые видео — **только по мотоциклетной теме**:
эндуро, мотокросс, выезды и путешествия, ремонт и экипировка,
истории реальных мотоциклистов.

**Единственный автоматический сервис публикации — Buffer.**
Ранее использовавшийся сервис публикаций отключён из действующих workflow;
общий контроль качества сохранён в `cloud-shorts/publication_safety.py`.

## Как работает фабрика

```text
Мототема и оригинальная идея
   ↓
Проверка фактов, уникальности, разрешений на исходные кадры
   ↓
GitHub Actions daily-preview → озвучка → музыка → FFmpeg → MP4
   ↓
voice_qa + mixed_audio_qa + editorial_guard + channel_focus
   ↓ (только если все проверки пройдены, выпуск одобрен и не повторяется)
buffer-backlog → GitHub Releases (стабильная ссылка на MP4)
   ↓
Buffer очередь → YouTube GUSTAVA Enduro
```

### Автоматические задачи

- [Ежедневная фабрика MP4](.github/workflows/daily-preview.yml):
  до трёх попыток генерации в сутки, без личного контента пользователя.
- [Поиск мотоисторий](.github/workflows/continuous-stories.yml):
  дважды в день, новые идеи проходят проверку перед выпуском.
- [Постановка MP4 в Buffer](.github/workflows/buffer-backlog.yml):
  автоматически после успешного рендера и дополнительно четыре раза в день.
- [Проверка подключения Buffer](.github/workflows/buffer-readiness.yml):
  только чтение реального канала, расписания и количества постов.
- [Полный набор автоматических тестов](.github/workflows/validate-pipeline.yml).

Подробности, диагностика, экстренное отключение автопубликации и ссылки:
**[AUTOPILOT_SETUP_RU.md](AUTOPILOT_SETUP_RU.md)**.

## Защита от ошибок

- Публиковать можно только оригинальные мото-Shorts с `auto_publish:true`,
  голосом `kokoro_ru_dima`, документированными правами и полным QA MP4.
- Две дорожки голоса, пропущенные русские слова, недостающие кадры,
  продолжительное зависание изображения и повторные исходники должны
  приводить к отказу от публикации, а не к выдаче дефектного ролика.
- При неопределённом ответе Buffer новая попытка автоматически не делается.
  Реестры сохраняют и старые публикации, чтобы не было дублей.
- Ролики про воду, авиацию, животных и иные посторонние темы
  исключены из активной очереди и заблокированы редакционным фильтром.
- Видео из личных папок Windows и Music Studio не используются.
- Публичные описания без ссылок на исходные видеоматериалы.
- Никаких ботов, накруток, искусственных комментариев или выдуманных просмотров.

**Важно:** успешный workflow не означает, что новое видео опубликовано.
Фактическая очередь и даты выхода проверяются в
[Buffer](https://publish.buffer.com/channels/6ae238b32f1f5ed648ff9011/schedule?tab=queue).

## Цель роста

Работаем над 1000 подписчиков и квалификационными порогами YouTube Partner
Program через связку оригинальных Shorts и содержательных длинных мотопрограмм.
Результат зависит от удержания, интереса аудитории, прав и правил YouTube;
10 млн просмотров, 4 тыс. часов и доход не гарантируются.
Метрики для корректировки стратегии берём из YouTube Studio, а не из
публичного счётчика просмотров без проверки квалификации.

Старые инструкции сохранены в истории Git и не являются действующей
конфигурацией проекта.
